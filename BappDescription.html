Turn Burp traffic into screenshots your report can actually use — without leaving your AI chat. ScreenBurp lets assistants such as OpenCode, Claude, and ChatGPT look at your Proxy history and hand you back a clean evidence PNG: the real request and response, the important parts highlighted, and secrets hidden by default.

It builds on PortSwigger's Burp MCP Server, so all the usual MCP tools are still there — sending requests, browsing history, Repeater, Intruder, Collaborator, config, and encoding helpers. ScreenBurp adds the screenshot tools on top. And it plays it straight: it never invents or rebuilds an HTTP message to make a nicer picture. If something can't be captured for real, you get a clear explanation instead of a fake image.

For more information about the protocol, visit modelcontextprotocol.io

Note: Any data sent to external tools via this extension is subject to their data processing policies.

What it adds

  • Screenshot any Proxy history entry, by position or by search — no tab-switching or manual cropping
  • Native captures that look like Burp because they are Burp: real message editors, your theme, your fonts
  • Smart captures for long responses — find the few lines that matter and shoot each one
  • Before/after diff evidence for exploits, with the payload and proof labelled for you
  • Highlights, numbered callouts, and red boxes around the bits you point at
  • Secrets blacked out by default — auth headers, cookies, tokens, passwords, and JWTs

Getting started

  1. Load the extension JAR via Extensions → Installed → Add (disable the official MCP Server first — they share a port).
  2. Open the "MCP" tab and switch the server on.
  3. Connect your MCP client to http://127.0.0.1:9876, or use the packaged stdio proxy server.
  4. Then just ask, in plain words: "Screenshot the login request that got a 401, highlight the status line, and hide any tokens."
